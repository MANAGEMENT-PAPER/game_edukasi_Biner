Petunjuk Kuis Biner 4-Bit

Prinsip Biner 4-Bit: Setiap posisi bit dari kiri ke kanan memiliki nilai posisi berbasis eksponen 2 (2³, 2², 2¹, 2⁰):

Bit 4
= 8
Bit 3
= 4
Bit 2
= 2
Bit 1
= 1

Contoh Konversi:

1 0 1 1 = (1×8) + (0×4) + (1×2) + (1×1)

= 8 + 0 + 2 + 1 = 11

⚠️ Perhatian: Selama permainan, label bantuan (8, 4, 2, 1) sengaja disembunyikan untuk menguji kecepatan ingatan Anda!
